# The Little Book of HAL

A gentle introduction to HAL (the hara language), in the style of
*The Little Lisper*: short question-and-answer dialogues that teach the
language one small idea at a time.

!!! note "Work in progress"
    This book is being written. The chapter outline is still open —
    watch this space.

Every example runs as-is in the hara REPL (`./hara` from the repository
root) or in the browser playground.

Planned progression:

1. Data — numbers, strings, collections, keywords
2. Functions — `fn`, `defn`, composition
3. Collections — sequences, transforms, laziness
4. Namespaces — projects, `require`, aliases
5. State and effects — promises, bytes, capabilities
6. Extensions — calling wasm from hara
