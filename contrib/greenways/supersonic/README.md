# Greenways Supersonic contribution

This contribution owns the Supersonic audio-graph specification and its
reference HAL/JavaScript adapter. Hara provides the portable data model,
metaspec verification, and local publication tooling; Greenways owns the audio
domain vocabulary and policy.

The draft normative specification is in `spec/draft/`. The reference adapter
remains usable by Hara Studio, but its source of truth is this contribution.
