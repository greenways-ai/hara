# Greenways contributions

Greenways-owned artifact formats live here as isolated contribution projects:

- `build/` — staged artifact construction and obligation reporting.
- `supersonic/` — the Supersonic audio graph format and reference adapter.
- `usdskel/` — a reserved scaffold for a future USD Skel format specification.

The normative Hara metaspec and generic verifier remain under `specs/` and
`lib/src/hara/metaspec/`. Greenways documents use `:greenways.*` identifiers and
are published by Hara only as explicitly attributed contributions.
