# Hara contributions

`contrib/` contains independently owned specifications and reference
implementations that are developed in the Hara repository but are not part of
the Hara language contract.

Each contribution has an owner-qualified identifier, its own project boundary,
and a `CONTRIBUTION.edn` envelope. Hara supplies the metaspec, verifier, codecs,
and publication pipeline. The named contributor owns the domain vocabulary and
acceptance policy.

Published copies are labelled as contributions on
[`specs.hara-lang.org`](https://specs.hara-lang.org/); publication does not
transfer ownership to Hara.
